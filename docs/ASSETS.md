# Original assets and attribution

All world sprites, building blocks, trees, cars, lane markings, service symbols, SVG icons and map graphics are generated by project code. No downloaded art, maps, passenger records, fonts, audio recordings or paid assets are required.

Music is an original four-note synthesized pattern; the engine and button effects use Web Audio oscillators. Fonts are system/browser fonts. Ònà Dispatch is a fictional original service identity. Names identify fictional passengers and a fictional driver.

Phaser, React, Vite, TypeScript, Vitest, Playwright and Prettier are third-party software dependencies with their own licenses in the installed packages. The game concept and foundation requirements came from the user-provided `Lagos_Uber_Driver_Foundation.docx` (version 1.0). There is no Uber logo, API integration or affiliation.
