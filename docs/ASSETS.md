# Original assets and attribution

All 3D buildings, shop signs, vegetation, geometric people, driver/passenger models, cars, danfo buses, billboards, pumps, service symbols, SVG icons and mini-map graphics are generated by project code. The layout is a fictional compressed Lagos-inspired street grid. It is not a real navigation map.

Afro groove and Highlife guitar are original synthesized loops. Engine, horn, ambient traffic and UI sounds use Web Audio oscillators. No commercial music or real radio broadcast is bundled. User music is imported locally.

No authentic Nigerian speech recordings are bundled yet. The game supports recorded Pidgin, Yoruba and Igbo dialogue, imports, explicit microphone recording and a shared voice manifest. Missing recordings use written lines and English translations, without substituting synthetic speech. See [voice recording instructions](VOICE_RECORDINGS.md); add credited speakers and consent/license references before shipping recordings. Native speaker review of the written dialogue is still needed.

Fonts are system/browser fonts. Ònà Dispatch and the example advertisements are fictional original identities. Names identify fictional passengers and a fictional driver. The game uses neither Uber’s logo nor its API.

Three.js, React, Vite, TypeScript, Vitest, Playwright and Prettier are third-party software dependencies with their own licenses in installed packages. The original foundation requirements came from the user-provided `Lagos_Uber_Driver_Foundation.docx` (version 1.0); the subsequent 3D, camera, traffic, passenger, radio, voice and billboard work follows the user’s direct request.
